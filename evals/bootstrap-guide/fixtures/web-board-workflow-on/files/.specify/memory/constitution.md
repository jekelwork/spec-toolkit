# Widgets Constitution

## Core Principles

### I. Spec-Driven Development

Every change traces back to an approved spec, plan and task.

### II. Review Before Merge

A pull request needs 0 independent approvals; the author may merge their own pull request.

## Governance

This constitution is amended by a pull request that states the reason for the change.
